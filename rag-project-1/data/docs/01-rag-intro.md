# RAG 基础：检索增强生成

## 什么是 RAG

检索增强生成（Retrieval-Augmented Generation，RAG）是一种让大语言模型在回答问题之前，先从外部知识库中检索相关文档片段，再把这些片段作为上下文交给模型生成答案的技术。它的核心目的是减少幻觉，让答案有据可查。

RAG 的典型流程分四步：文档解析与切分、向量化与索引、检索、生成。首先把 PDF、Word、网页等文档切成小块，每块一般几百个字符；然后把每块编码成向量存入向量库；用户提问时，先检索出最相关的若干块；最后把问题和检索到的块一起交给大语言模型生成带引用的答案。

## 切分策略

切分策略直接影响检索质量。切得太碎会丢失上下文，切得太大又会引入无关噪声。常见做法是按标题和段落切分，块大小控制在 300 到 800 个字符之间，相邻块保留 50 到 100 个字符的重叠，避免关键句子被切断在两块之间。

## 混合检索

单一检索方式各有短板。向量检索擅长语义相近的内容，但对精确术语、编号、人名不敏感；关键词检索（BM25）擅长精确匹配，但不懂同义词。混合检索把两者结合：先用 BM25 和向量检索各取 Top-K，再合并去重，能同时覆盖精确匹配和语义匹配。

## 重排

重排（rerank）是在检索之后、生成之前加一道精排。先用召回率高的粗排取回 20 到 50 个候选块，再用交叉编码器模型（如 bge-reranker）逐对打分，只把得分最高的 3 到 5 块交给模型生成。重排能显著提高交给模型的上下文质量，是 RAG 系统中最划算的优化之一。

## 幻觉控制

幻觉控制靠三件事：第一，检索不到相关内容时明确拒答，而不是编造答案；第二，要求模型只依据提供的上下文作答，超出上下文的问题直接说明不知道；第三，答案必须带引用，标明每句话来自哪篇文档的哪一块，方便人工核查。
